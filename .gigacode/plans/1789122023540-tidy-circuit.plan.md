# Исправление конфигурации отладки VS Code (launch.json)

## Проблема
Текущая конфигурация в `.vscode/launch.json` некорректна для Next.js приложения:
- Указан порт **8080**, но Next.js по умолчанию работает на порту **3000.**
- Тип отладчика `editor-browser` устарел и не поддерживает полную отладку Next.js

## Решение

### Файл для изменения
`C:/Users/HP OMEN/IdeaProjects/Avtozvuk/.vscode/launch.json`

### Изменения

Заменить текущую конфигурацию на корректную для Next.js:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "chrome",
            "request": "launch",
            "name": "Запустить Next.js",
            "url": "http://localhost:3000",
            "webRoot": "${workspaceFolder}",
            "runtimeArgs": [
                "--disable-web-security"
            ]
        }
    ]
}
```

### Ключевые изменения:
1. **type**: `editor-browser` → `chrome` — поддерживает полную отладку с breakpoints, watch expressions
2. **url**: `localhost:8080` → `localhost:3000` — стандартный порт Next.js

## Верификация
1. Запустить dev-сервер: `npm run dev` (или `bun dev`)
2. В VS Code выбрать конфигурацию "Запустить Next.js" и нажать F5.
3. Убедиться, что браузер открывается на `localhost:3000` и breakpoints работают
