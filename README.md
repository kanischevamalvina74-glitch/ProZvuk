## Telegram-бот выдачи Pro-ключей

Наш бот: **@avt0zvuk_pro_bot** — https://t.me/avt0zvuk_pro_bot

Бот принимает оплату 100 ₽, по команде админа выдаёт покупателю подписанный
лицензионный ключ, покупатель активирует его на сайте в личном кабинете.

### Запуск бота — три способа (нужен обычный интернет; в облаке Telegram заблокирован)

**Способ 1 — готовый exe для Windows (ничего устанавливать не нужно):**

1. Скачайте архив бота: `<адрес-превью>/avtozvuk-bot.zip`
   (файл лежит в `public/` проекта и хранится в git, так что ссылка живёт
   постоянно). Внутри — `avtozvuk-bot.exe` и образец конфига.
2. Распакуйте архив в любую папку. Рядом с exe создайте файл `.env`
   (без расширения!) со строками:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=284199866
   ```
3. Запустите exe двойным кликом. В открывшемся окне появится ссылка на бота —
   `t.me/имя_бота`. Окно должно оставаться открытым, пока бот нужен.

**Способ 2 — через Node.js 18+ (Windows/macOS/Linux):**

```bash
node bot/index.mjs
```

или `bun bot/index.mjs`. Конфиг — тот же файл `.env` в папке проекта.

**Способ 3 — на сервере рядом с сайтом (круглосуточно, без ПК):**

Позже бот можно перенести в тот же контейнер Cloud.ru, где работает сайт —
тогда он будет отвечать покупателям 24/7.

### Команды бота

| Команда            | Кто     | Что делает                                    |
| ------------------ | ------- | --------------------------------------------- |
| `/start`, `/help`  | все     | Справка покупателю: как купить и активировать |
| `/whoami`          | все     | Показывает свой Telegram ID                   |
| `/issue email`     | админ   | Выдаёт ключ Pro для указанного email          |

### Сценарий продажи

1. Покупатель платит 100 ₽ и сообщает свой email (с сайта).
2. Вы пишете боту: `/issue email@покупателя.ru`
3. Бот присылает готовый ключ — пересылаете покупателю.
4. Покупатель вставляет ключ на сайте: `/account` → Pro активирован.

### Админ-панель сайта (`/admin`)

Скрытая страница (noindex, нигде не ссылается): вся модель монетизации,
воронка покупки, статус переменных окружения и генератор ключей без бота.

- Пароль по умолчанию: `avtozvuk-admin-v1` — только для теста.
- Боевой режим: задайте `ADMIN_PASSWORD` и одинаковый `LICENSE_SECRET`
  на сайте и в боте в переменных окружения.
- Ключ из админки совпадает с ключом бота для того же email.
